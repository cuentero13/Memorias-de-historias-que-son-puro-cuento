# Memorias de historias que son puro cuento
Memoria institucional de la **Fundación Festival Puro Cuento** (Costa Rica) — festival de narración oral / cuentería.

## Estructura
- `ediciones/` — una carpeta por edición del festival (año, sede, invitados, fotos)
- `cuenteros/` — fichas de narradores invitados
- `fotos/` — material fotográfico organizado por edición

## Nota
El material (fotos, listas de invitados, programas) lo aporta el equipo de la Fundación. Este repo es el esqueleto inicial.
